# 🌀 LLM-Consensus-Router: High-Quality AI for $0.00

Get GPT-4 quality outputs using free, local models! **LLM-Consensus-Engine** is an open-source, ultra-fast routing gateway that queries multiple free local LLMs (like Llama3, Mistral, and Phi3) concurrently. It pools their answers to eliminate individual model blindspots, giving you reliable, high-tier AI results for exactly **$0.00**.

## 🚀 Features
* **Multi-Model Concurrency:** Fires requests to several local models at the exact same time.
* **Higher Accuracy:** Combines the strengths of different open-source architectures to reduce hallucinations.
* **Zero Cost Infrastructure:** No subscription fees, no API keys, and 100% offline data privacy.

## 🛠️ How to Run (For Users)

### 1. Clone the repository
```bash
git clone https://github.com
cd llm-consensus-router
```

### 2. Install dependencies
```bash
pip install -r requirements.txt
```

### 3. Run the Consensus Proxy
```bash
python app.py
```

*Note: Ensure Ollama is running with your chosen models downloaded before sending requests.*
